# 2026-10-27 计划：反复读与反模板

> 状态：计划中（未实现）
> 日期：2026-10-27
> 关联：[总计划](./2026-10-27-拟人化改造总计划.md)

## ① 现象（真群实测）

- `剑魔` 27/36 条（75%）、`刮痧` 44%、`半管血` 17%、`有这功夫` 19%；
- 首句坍缩：`卧槽…`×4、`傻逼…`×5、`正搁这刮痧呢` 反复；
- 结尾趋同：`有这功夫不如滚去排单`、`有屁快放没屁滚`；
- 逐字复读：第 19/22 条"卧槽心之钢焚天剑魔 肉得发瘟"几乎相同；
- 一个主题锁死 47 分钟，无论对方说什么都拉回剑魔。

## ② 根因

1. **历史自我强化**：持久化对话里 bot 自己反复说剑魔 → 作为上下文再次强化；
2. **RAG 锚定**（见 RAG 工具化计划）：召回旧片段进一步固化用词；
3. **无多样性约束**：生成后没有任何"你最近说过这些，换点别的"的反馈。

## ③ 设计

### 3.1 近期高频词统计

- 维护每个场景最近 `N`（默认 20）条 **assistant** 回复；
- 统计 2~4 字 n-gram / 关键词频率；
- 超过阈值（如出现 ≥3 次且占比 ≥25%）的词进入"过热词表"。

### 3.2 生成前提醒（prompt）

- 在 system 末尾追加**动态**提示（注意：会破坏 KV 缓存，需权衡；可放 user 前）：
  `你最近老说"剑魔、刮痧、傻逼"，这轮尽量换个说法。`
- 动态提示放在历史之后、当前消息之前，作为独立 `system`/`user` 片段。

### 3.3 生成后处理（硬约束）

- `applyStyle` 之后增加"反模板"步骤：
  - 若回复命中过热词，按概率替换/删除；
  - 若与最近 `K` 条回复高度相似（编辑距离/最长公共子串超阈值），重写或丢弃该条；
  - 同一条回复内避免重复同一短语。

### 3.4 话题轮换（可选）

- 若连续 `M` 轮都围绕同一实体（如"剑魔"），强制本轮不主动提及该实体，
  除非用户当前消息明确在说它。

## ④ 配置项

| env | 默认 | 说明 |
|---|---|---|
| `HL_ANTIREPEAT_WINDOW` | 20 | 统计窗口（最近多少条自己的回复） |
| `HL_ANTIREPEAT_MIN_COUNT` | 3 | 过热词最小出现次数 |
| `HL_ANTIREPEAT_RATIO` | 0.25 | 过热词占比阈值 |
| `HL_ANTIREPEAT_REPLACE_PROB` | 0.5 | 命中过热词后的替换概率 |
| `HL_ANTIREPEAT_SIM_THRESHOLD` | 0.7 | 与近期回复相似度阈值 |

## ⑤ 文件改动

| 文件 | 改动 |
|---|---|
| `agent/core.ts` | 维护近期回复窗口；flush 时生成过热词；调用反模板后处理 |
| `agent/profile.ts`（或新 `antirepeat.ts`） | 实现 n-gram 统计、相似度、替换 |
| `agent/prompt.ts` | 支持动态"过热词"提示片段 |
| `agent/config.ts` | 新增配置项 |

## ⑥ 测试

- 构造连续 10 条都含"剑魔"的模拟对话 → 过热词表命中；
- 生成含"剑魔"的回复 → 按概率替换/重写；
- 真群灰度对比：`剑魔` 出现率从 75% 降到 <15%。

## ⑦ 风险

- 过度去重会损伤人设一致性（本人确实常聊游戏）；
- 缓解：只针对"高频且低信息量"的模板词，保留人格底色；
- 动态提示破坏 KV 缓存 → 可接受（命中率下降，但换来自然度）。
