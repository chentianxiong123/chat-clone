# 2026-10-27 计划：脏话限流

> 状态：计划中（未实现）
> 日期：2026-10-27
> 关联：[总计划](./2026-10-27-拟人化改造总计划.md)

## ① 现象

- 真群 36 条回复中 `傻逼` 13 条（36%）、`他妈` 9 条（25%）；
- 出现 `有屁快放没屁滚` 等攻击性表达；
- 明月问"你是人吗"，回"卧槽灵异事件 妈的 你们是不是有病"——超出"损/调侃"人设；
- 此前 `bb7313d` 已把硬替换改为 prompt 诱导，但**没有压住**。

## ② 根因

- 纯 prompt 诱导对 flash 小模型约束力不足；
- 缺少生成后的硬约束；
- 历史里脏话多 → 自我强化。

## ③ 设计

### 3.1 保留人设，限制密度

目标不是禁脏话，而是"脏字当调味料，偶尔一句"：
- 单条回复脏字数上限（默认 1）；
- 超出则按概率删除/替换；
- 连续多条都带脏话 → 强制本轮清零。

### 3.2 分级词表

| 级别 | 例子 | 处理 |
|---|---|---|
| 轻 | 他妈/妈的/卧槽 | 允许，计入密度 |
| 中 | 傻逼/蠢货 | 限频，超限替换为"损"表达 |
| 重 | 侮辱家人/极端攻击 | 直接替换或删除 |

### 3.3 后处理实现

- 在 `applyStyle` 之后、发送之前执行 `limitProfanity(reply, window)`；
- 保留标点/语气，只替换词本身；
- 替换表可配（默认温和化：傻逼→离谱/蠢、他妈→真、有屁快放→有事快说）。

### 3.4 与反模板协同

- 脏话高频词同样进入"过热词表"，双重抑制。

## ④ 配置项

| env | 默认 | 说明 |
|---|---|---|
| `HL_PROFANITY_MAX_PER_MSG` | 1 | 单条脏字上限 |
| `HL_PROFANITY_SOFTEN_PROB` | 0.7 | 超限时的替换概率 |
| `HL_PROFANITY_WINDOW` | 5 | 连续多少条内统计 |
| `HL_PROFANITY_HARD_BLOCK` | true | 重级词直接替换 |

## ⑤ 文件改动

| 文件 | 改动 |
|---|---|
| `agent/profile.ts`（或新 `profanity.ts`） | 词表 + `limitProfanity` |
| `agent/core.ts` | `applyStyle` 后调用限流 |
| `agent/config.ts` | 新增配置项 |
| `agent/.env.example` | 说明 |

## ⑥ 测试

- 构造含 3 个脏字的回复 → 限流到 ≤1；
- 连续 5 条都带脏话 → 第 6 条强制清零；
- 真群对比：脏话率从 36% 降到 <10%。

## ⑦ 风险

- 替换过度会让人设变"乖"，失去本人味道；
- 缓解：轻级词放行，只压中/重级与密度。
