## ③ 能力全景（当前实现）

### 3.1 接入层
- 个人号 NapCat → OneBot 正向 WS（`node-napcat-ts`）。
- 群消息、私聊消息双通道接收；断线重连、连接状态上报 WebUI。

### 3.2 对话层
- **攒批**：群聊 N=5 条 / T=60s；私聊 N=1 条 / T=15s。
- **触发模式**：`auto`（自动接话）/ `mention`（必须 @ 或唤醒词）。
- **唤醒词**：`崽种,qq,机器人,艾特我`（可配）。
- **场景体系**：群聊 / 私聊分场景，各自独立 system prompt、独立记忆、独立策略。
- **回车分割逐条发送**：回复按换行拆成多条，模拟真人一条条发。
- **白/黑名单**：`ALLOW_SCENES` / `DENY_SCENES`（`g:群号` / `p:QQ号`）。

### 3.3 拟人层（HumanProfile A~E，全部可配）
- A 触发应答：回复概率、敷衍短消息忽略。
- B 反应与节奏：随机反应延迟、冷却、刷屏抑制。
- C 打字节奏：按字数/速度算打字时间、条间停顿、拆条上限、首条迟疑。
- D 话术风格：长度收敛、表情、语气词、错别字、回敬关键词（LLM 输出后轻量后处理）。
- E 日程节律：静默时段、半醒时段、主动冒泡。
- 数据挖掘：`mine.ts` 读 jsonl → `buildProfileFromStats()` → `data/profile.json` → 启动覆盖（`HL_PROFILE_SOURCE=auto`）。

### 3.4 记忆层
- 即时上下文 `MAX_HISTORY=40` 轮。
- sqlite 持久化（重启不丢），按场景 key（`g:群号` / `p:QQ号`）。
- token 估算（中文 0.6/字、英文 0.3/字、emoji 2.0）。
- 超 `MEMORY_MAX_TOKENS=16384 × 0.82` 触发 LLM 摘要压缩，保留最近 15% 轮次，摘要以「user 摘要 + assistant 收到」注入。

### 3.5 RAG 层

- `topK=3`，命中格式化为「本人过往真实原话」作为独立 user 消息放对话**尾部**。
- **KV 缓存友好**：system prompt 字节级静态（不含 RAG），长前缀稳定可命中。

### 3.6 配置层

## ⑦ 已知边界 / 未完成

1. **数据挖掘已打通，但仍是「离线批处理」**：`npm run mine` 重新统计并写 `data/profile.json`；没有增量/定时更新，向量库与画像也不联动。
2. **单群为主**：多群/私聊代码保留，但不投入打磨。
3. **非文本消息**：图片、语音、表情包、@ 解析未处理。
4. **风格后处理有误伤风险**：错字替换、长度截断是概率性文本操作，极端情况会切坏语义。
5. **记忆只到「摘要」**：没有结构化的人物档案/事实抽取（喜好、关系、事件时间线）。
6. **压缩触发少**：40 轮 / 16384 token 下日常几乎不触发，摘要链路缺真实压测。
7. **主动性默认关**：proactive 未启用；drowsy 已由画像启用（02–03、08–10）。
8. **风控有限**：只有冷却 + burst，没有全局发送配额/敏感词/失败重试退避。

行为特征落地（本轮新增，全部可配 + 从库导入）：
- **对话状态**：距上次本人发言 <1min / 1–5min / 5–30min / >30min → 回复率 **99% / 74% / 47% / 39%**；被 @ / 唤醒强制 1。以「本人最后一条消息」为静默起点，比按上一轮首条回复更贴近真实冷场，故 cold/veryCold 比初版分析低。
- **分时段**：24 小时绝对回复率 → 乘数（07 `0.49` / 08 `0.76` / 09 `0.89`；03–06 样本 <30 回退整体率），与静默时段叠加。
- **经验延迟**：按 0–2/2–3/3–5/5–10/10–30/30–60/60–300s 桶权重采样（min 1.5s / max 13s，绝不秒回）。
- **单条长度**：`maxSegmentChars=14`，超长在标点处再拆，避免一条发一大段。
- **连发惩罚**：对方一次 ≥10 条 → 回复率 ×`0.86`。
- 配置：`HL_STATE_*` / `HL_REPLY_HOURLY` / `HL_REACT_DIST` / `HL_BATCH_PENALTY_*` / `HL_MAX_SEGMENT_CHARS`；WebUI 新增「分时段回复」卡与状态概率。

近期状态模型（本轮新增，全局单例 + 事件驱动 + 指数衰减）：
- **数值**：精力/心情/耐心/社交电量/忙碌/烦躁/兴趣/专注 + 近期消息/回复量、连发、话题热度；0~1，事件更新后按半衰期回基线。
- **基线**：精力按画像 `hourRatio`（或 24 小时曲线），忙碌按 `HL_STATE_BUSY_HOURS`（09–12、14–18），其余可配。
