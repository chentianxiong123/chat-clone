## ③ 能力全景（当前实现）

### 3.1 接入层
- 个人号 NapCat → OneBot 正向 WS（`node-napcat-ts`）。
- 群消息、私聊消息双通道接收；断线重连、连接状态上报 WebUI。

### 3.2 对话层
- **攒批**：群聊 N=5 条 / T=60s；私聊 N=1 条 / T=15s。
- **触发模式**：`auto`（自动接话）/ `mention`（必须 @ 或唤醒词）。
- **唤醒词**：`崽种,qq,机器人,艾特我`（可配）。
- **场景体系**：群聊 / 私聊分场景，各自独立 system prompt、独立记忆、独立策略。
- **回车分割逐条发送**：回复按换行拆成多条，模拟真人一条条发。
- **白/黑名单**：`ALLOW_SCENES` / `DENY_SCENES`（`g:群号` / `p:QQ号`）。

### 3.3 拟人层（HumanProfile A~E，全部可配）
- A 触发应答：回复概率、敷衍短消息忽略。
- B 反应与节奏：随机反应延迟、冷却、刷屏抑制。
- C 打字节奏：按字数/速度算打字时间、条间停顿、拆条上限、首条迟疑。
- D 话术风格：长度收敛、表情、语气词、错别字、回敬关键词（LLM 输出后轻量后处理）。
- E 日程节律：静默时段、半醒时段、主动冒泡。
- 数据挖掘接口：`buildProfileFromStats()` 骨架 + 字段映射蓝图（未实现）。

### 3.4 记忆层
- 即时上下文 `MAX_HISTORY=40` 轮。
- sqlite 持久化（重启不丢），按场景 key（`g:群号` / `p:QQ号`）。
- token 估算（中文 0.6/字、英文 0.3/字、emoji 2.0）。
- 超 `MEMORY_MAX_TOKENS=16384 × 0.82` 触发 LLM 摘要压缩，保留最近 15% 轮次，摘要以「user 摘要 + assistant 收到」注入。

### 3.5 RAG 层
- 三路检索：**vec（sqlite-vec）+ fts5 + like** 兜底。
- `topK=3`，命中格式化为「本人过往真实原话」作为独立 user 消息放对话**尾部**。
- **KV 缓存友好**：system prompt 字节级静态（不含 RAG），长前缀稳定可命中。

### 3.6 配置层
- 全部走 `.env`；`.env.example` 全量注释。
- 拟人参数集中在 `config.humanlike` 单一来源（旧的散落字段已移除）。
- WebUI 可在页面直接编辑 env 并保存。

### 3.7 WebUI（:8085）

## ⑦ 已知边界 / 未完成

1. **数据挖掘未做**：`buildProfileFromStats()` 是空实现，参数仍来自手填 env，没有「导入原始库 → 解出规律/作息」的闭环。
2. **单群为主**：多群/私聊代码保留，但不投入打磨。
3. **非文本消息**：图片、语音、表情包、@ 解析未处理。
4. **风格后处理有误伤风险**：错字替换、长度截断是概率性文本操作，极端情况会切坏语义。
5. **记忆只到「摘要」**：没有结构化的人物档案/事实抽取（喜好、关系、事件时间线）。
6. **压缩触发少**：40 轮 / 16384 token 下日常几乎不触发，摘要链路缺真实压测。
7. **主动性与节律默认关**：drowsy / proactive 未启用。
8. **风控有限**：只有冷却 + burst，没有全局发送配额/敏感词/失败重试退避。

## ⑧ 下一步建议（按优先级）

### P0 · 数据挖掘闭环（用户明确的目标）
把「参数从数据中来」打通：
1. 定义标准统计输入：从 `chat_records/` 原始库（QQ/微信）抽取时间戳、消息长度、连发条数、词频、应答比。
2. 实现 `buildProfileFromStats(rawStats) → HumanlikeProfileOverride`：
   - 回复前置间隔分布 → `react.minMs/maxMs`
   - 同人连发间隔 → `typing.segGap` / `charsPerSec`
   - 单轮长度分位（P80）→ `style.maxChars`
   - 表情/语气词/错字词频 → `style.*`
   - 分时段活跃量 → `schedule.quietHours` / `drowsy`
   - 消息→回复应答比 → `replyProb`
3. 产出 `profile.json`，启动时覆盖 env；`HL_PROFILE_SOURCE=db:<统计表>`。
4. WebUI 增加「画像来源 / 统计概览」页。

### P1 · 拟人深化
- 结构化人物档案（事实记忆），比摘要更稳。
- 图片/表情消息理解与回复。
- 主动性 + 日程节律真正启用并调参。

### P2 · 稳定性 / 观测
- 全局发送配额、敏感词、失败退避。
- 记忆压缩真实压测与摘要质量评估。
- 多群支持与 per-peer 覆盖。
