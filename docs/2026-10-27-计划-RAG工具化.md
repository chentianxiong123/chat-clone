# 2026-10-27 计划：RAG 工具化（function call）

> 状态：计划中（未实现）
> 日期：2026-10-27
> 关联：[总计划](./2026-10-27-拟人化改造总计划.md)

## ① 目标

把"每轮把 RAG 结果当 `user` 参考资料注入"改成 **function call 工具**：
- `search_past_memory`：按需查往事；
- `remember`：记住关于朋友的事实；
- 倾向主动使用，但当前对话始终是主上下文。

## ② 现状问题（代码证据）

- `core.ts:371` 每次 `flush` 都 `await searchRag(ctx)`，无条件检索；
- `prompt.ts:34` `buildRagContextMessage` 把结果作为 **`role:'user'`** 消息插在历史后、当前消息前，
  文案"以下是本人过往说过的真实原话作为参考，说话就这味道"→ 模型进入检索问答/客服模式；
- `rag.ts:167` `searchRag` 用关键词匹配当前消息 → 命中什么话题就注入什么历史片段 → 注意力被锚定；
- 直接后果：`👴`、`位不见王`、剑魔 等旧片段被召回并自我强化（真群已复现）。

## ③ 锁定决策

- 用 **function call（进程内）**，不用 MCP。
- 两个工具都加，且**鼓励调用**。
- 工具结果极小（默认 1 条、≤60 字），措辞"隐约记得…别复述/别改话题"。
- 保留**规则闸门**兜底：即使模型不调，命中"过去指代"也能回忆。
- `remember` 写入可写的 `memory.db`（RAG 库是 `readOnly`，不能写）。

## ④ 设计

### 4.1 工具契约

```
search_past_memory({ query: string }) -> string
  说明：仅当需要回忆过去发生的具体事情、或对方提到"上次/之前/你说过/记得"时优先调用。
  返回：`（你隐约记得：<一句>）` 或 `（没想起来）`

remember({ fact: string }) -> string
  说明：听到关于朋友的稳定事实/喜好/约定时记住（≤60 字）。
  返回：`（记住了）`
```

### 4.2 有界工具循环

`callLlmWithTools(messages, { tools, executors, maxIter })`：
1. 复用现有 provider/fallback 链与计费；
2. 发送前把消息清洗为纯 OpenAI 结构（剥掉内部 `time` 字段）；
3. 循环 ≤`RAG_TOOL_MAX_ITER`（默认 2）：
   - `create({ tools, tool_choice:'auto' })`；
   - 若返回 `tool_calls` → 执行 → 追加 `assistant(tool_calls)` + `tool` 结果 → 继续；
   - 否则返回最终文本；
4. 每次调用都 `recordUsage`；
5. **降级**：provider 报"不支持 tools"时，回退为单次无 tools 调用（用闸门预取记忆）。

### 4.3 规则闸门（兜底）

```
needsRecall(text) = 命中过去指代关键词（上次/之前/你说过/记得/那时候/是不是说过…）
gate = needsRecall(ctx) || Math.random() < RAG_RECALL_PROB
```
- `gate` 命中 → 先检索一条，作为 `system` "隐约记得"注入；
- 不命中 → 不注入，交给模型自主决定是否调工具。

### 4.4 注入形态

- 记忆提示用 `role:'system'`（**不是 user**）：
  `（你隐约记得：…；这是印象，不是现在有人说的话，别复述、别改话题）`
- 位置：历史之后、当前 user 消息之前，或 system 末尾；不贴着当前消息。

## ⑤ 数据流

```
攒批 ctx
  → [闸门] 过去指代? / 随机 RECALL_PROB?
       命中 → 预取一条"隐约记得"(system)
  → messages = system + hist + (记忆提示) + userMsg
  → callLlmWithTools(两工具, ≤2 轮)
  → applyStyle → 分段发送
  → 只持久化 user/assistant（工具消息与记忆提示不入库）
```

### facts 表

```sql
CREATE TABLE IF NOT EXISTS facts(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  scene_key TEXT NOT NULL,
  fact TEXT NOT NULL,
  ts INTEGER NOT NULL,
  UNIQUE(scene_key, fact)
);
```

## ⑦ 配置项（`config.rag`）

| env | 默认 | 说明 |
|---|---|---|
| `RAG_TOOLS_ENABLED` | true | 总开关，关闭则回退旧单次路径（不带工具） |
| `RAG_RECALL_PROB` | 0.15 | 无过去指代时的主动回忆概率 |
| `RAG_TOOL_MAX_ITER` | 2 | 工具循环上限 |
| `RAG_TOOL_MAX_ITEMS` | 1 | 每次检索注入条数 |
| `MEMORY_FACT_MAX_CHARS` | 60 | `remember` 单条长度上限 |

## ⑧ 测试

- 加载：`node --import tsx -e "import('./tools.ts')"`；
- 工具直测：`remember("朋友喜欢吃火锅")` → `searchFacts` 能查到且去重；
- 集成：模拟"上次你说要买耳机" → 触发检索；普通闲聊 → 不注入记忆（看日志）；
- 回归：确认 `👴`/剑魔 不再由 RAG 注入（只应来自最近对话）。

## ⑨ 风险与缓解

| 风险 | 缓解 |
|---|---|
| 小模型不调工具（丢记忆） | 规则闸门兜底 |
| 小模型乱调（污染） | `tool_choice:'auto'`+描述约束+≤2 轮+1 条 |
| 幻觉写入 `remember` | 规范化+去重+长度上限+场景隔离 |
| provider 不支持 tools | 捕获错误降级为单次无工具调用 |
| 延迟/成本 +1 轮 | 仅"需要回忆"时发生，且 ≤2 轮；per-call 计费 |

## ⑩ 待确认

3. 工具调用轨迹是否在 WebUI 展示（先只写日志）。
